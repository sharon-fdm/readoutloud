# ReadOutLoud

A small macOS SwiftUI app for opening a text or Markdown file, placing the cursor anywhere in the rendered text, and reading aloud from that exact position.

## Features

- Open plain text or Markdown files
- Click anywhere in the text to choose the reading start point
- Read aloud from the selected cursor location
- Stop and reset playback cleanly
- Zoom text in and out

## Build

```bash
swift build
```

## Run

```bash
swift run
```
